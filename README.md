# snack-box

小游戏合集，每个游戏一个目录，各自独立。

## 收录

### Echo Corridor / 回声走廊

2D 声波迷宫：摸黑走进迷宫，靠回声看清墙壁。

背景全黑，玩家、声波和墙壁都是白色。玩家移动时不断发射声波，波前扫过的墙壁被点亮，
然后逐渐衰减回黑色——走廊的轮廓只在回声里短暂存在。声波不考虑反弹与遮挡。

迷宫按难度（低 / 中 / 高）生成，影响地图尺寸、声波可见半径与墙壁衰减时长；可指定随机种子复现同一张地图。
另有 Agent 模式，可配置 OpenAI 兼容接口让模型自动走迷宫。

Godot 4.7（.NET / C#）。目录说明与本地运行方式见 [`Echo Corridor/`](Echo%20Corridor/)。
